# Whispr 💬

A modern **messaging web application built with Vue.js** that demonstrates authentication flow, dynamic routing, and modular UI design.

Whispr is designed as a lightweight chat-style application showcasing best practices in **Single Page Application (SPA) development**.

---

# 📌 Overview

Whispr is a Vue.js-based messaging interface designed to explore modern frontend architecture including:

* Component-driven UI development
* Authentication and navigation flow
* Structured project architecture
* Clean and responsive interface design

The project demonstrates how to structure a scalable Vue application while keeping the code modular and maintainable.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/abinet22/Whispr.git
```

Move into the project folder

```bash
cd Whispr
```

Install dependencies

```bash
npm install
```

---

# 🚀 Run Development Server

```bash
npm run serve
```

The app will run at:

```
http://localhost:8080
```

---

# 🏗 Build for Production

```bash
npm run build
```

This creates an optimized production build.

---

# 🧹 Lint and Fix Files

```bash
npm run lint
```
